# دعوة زفاف محمد & روان

صفحة دعوة زفاف عربية، ملف واحد مكتفٍ بذاته بدون أي تبعيات أو خطوة بناء.

**الروابط**

- Vercel (الرابط الأساسي للمشاركة): https://mohamed-w-rawan.vercel.app
- GitHub Pages: https://mdakrory.github.io/Wedding/

## تفاصيل الحفل

| | |
|---|---|
| التاريخ | الإثنين ٩ نوفمبر ٢٠٢٦ |
| الوقت | ٦:٠٠ مساءً (توقيت مصر) |
| المكان | قاعة إيليت — طلخا، الدقهلية |

## التعديل

كل النصوص والتواريخ في كتلة `CONFIG` في أول الـ `<script>` داخل `index.html`:

```js
var CONFIG = {
  groom:  "محمد",
  bride:  "روان",
  dateISO:"2026-11-09T18:00:00+02:00",  // توقيت مصر
  venue:  "قاعة إيليت",
  city:   "طلخا — الدقهلية",
  mapsUrl:"https://maps.app.goo.gl/sm8bgsqRGnw9xVNDA"
};
```

التاريخ الهجري مكتوب يدوياً في بطاقة «التاريخ» داخل `index.html` (حساب جدولي، قد يفرق يوم).

## المعاينة محلياً

```bash
python -m http.server 8777
```

ثم افتح `http://localhost:8777`.

## النشر

أي `git push` على فرع `main` بينشر تلقائياً على Vercel و GitHub Pages.

`vercel.json` بيضبط الموقع كملفات ثابتة بدون بناء، وبيمنع الكاش على `index.html` عشان أي تحديث يبان فوراً.
